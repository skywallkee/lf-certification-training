## Roles and objects

<Flow label="Gateway API ownership" steps={["GatewayClass (infrastructure provider)", "Gateway (cluster operator)", "HTTPRoute (app developer)", "Service"]} />

```yaml
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: store
spec:
  parentRefs:
    - name: public-gateway
  hostnames: ["store.example.com"]
  rules:
    - matches:
        - path: { type: PathPrefix, value: /api }
      backendRefs:
        - name: store-api
          port: 8080
```

<Callout kind="note" title="Attachment is two-way">
A route names its Gateway in `parentRefs`, and the Gateway's listener must allow routes from the route's
namespace. Check the route's `status.parents` when traffic does not arrive.
</Callout>
