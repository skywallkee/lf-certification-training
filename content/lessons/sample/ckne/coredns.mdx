## The Corefile lives in a ConfigMap

```bash
kubectl -n kube-system get configmap coredns -o yaml
```

```text
.:53 {
    errors
    health
    kubernetes cluster.local in-addr.arpa ip6.arpa {
       pods insecure
       fallthrough in-addr.arpa ip6.arpa
    }
    forward . /etc/resolv.conf
    cache 30
    loop
    reload
}
corp.example:53 {
    forward . 10.0.0.10
}
```

The second block sends `corp.example` lookups to a company resolver. The `reload` plugin picks up the
change without restarting Pods.
