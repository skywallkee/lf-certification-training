## What the kubelet looks for

The container runtime reads CNI configuration from `/etc/cni/net.d/` and plugin binaries from
`/opt/cni/bin/`. The first configuration file in lexical order wins.

```bash
ls /etc/cni/net.d/
ls /opt/cni/bin/
kubectl get pods -n kube-system -o wide
```

A node reports `NotReady` with "network plugin not ready" until a CNI configuration exists. Install the
plugin's manifests, then watch the node turn `Ready`.
