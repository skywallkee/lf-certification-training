## Start a rollout

```bash
kubectl set image deployment/web web=nginx:1.28
kubectl rollout status deployment/web
```

The Deployment creates a new ReplicaSet and shifts Pods to it within `maxSurge` and `maxUnavailable`
(25% each by default).

## Roll back

```bash
kubectl rollout history deployment/web
kubectl rollout undo deployment/web            # previous revision
kubectl rollout undo deployment/web --to-revision=2
```

<Callout kind="note" title="Only template changes roll">
A rollout starts when the Pod template changes. Scaling the replica count does not create a revision.
</Callout>
