## Four objects

| Object | Scope | Holds |
|--------|-------|-------|
| Role | Namespace | Rules (verbs on resources) |
| ClusterRole | Cluster | Rules, or cluster-scoped resources |
| RoleBinding | Namespace | Subjects bound to a Role or ClusterRole |
| ClusterRoleBinding | Cluster | Subjects bound to a ClusterRole everywhere |

<Flow label="How a request is allowed" steps={["Subject", "RoleBinding", "Role rules", "Allowed verbs"]} />

## Grant read access to Pods

```bash
kubectl create role pod-reader --verb=get,list,watch --resource=pods -n dev
kubectl create rolebinding jane-reads-pods --role=pod-reader --user=jane -n dev
kubectl auth can-i list pods -n dev --as=jane    # yes
kubectl auth can-i delete pods -n dev --as=jane  # no
```

<Callout kind="tip" title="Reuse ClusterRoles in one namespace">
A RoleBinding can reference a ClusterRole. The permissions then apply only inside the binding's namespace.
</Callout>
