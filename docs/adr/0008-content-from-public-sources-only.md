# 8. Content comes from public sources only

Date: 2026-11-24 · Status: Accepted

## Context

Linux Foundation and CNCF exams are under NDA. Reproducing recalled exam tasks or questions would breach
it and put the platform and its learners at risk.

## Decision

Every lesson, question and lab task is written from the public curriculum, official project
documentation and original scenarios. Never from recalled or leaked exam content. Each content item lists
the competencies it covers, and reviewers check sources as part of review.

## Consequences

`content/README.md` states the rule for contributors and agents. Questions cite the documentation they
are based on.
